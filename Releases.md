# 0.1.0

First release of Ethos Gauges.

- Gauge widget with six types: arc, half arc, ring, horizontal bar, vertical bar and needle dial
- Any source, with a min/max range pre-filled from the source
- Fill color, source name and min/max labels configurable per slot
- Settings saved per widget slot in the model
- English and German
